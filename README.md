# Игра «Путь к замку» (консольная, Java)

Проект по курсу «Разработка мобильных игр». Собран строго на темах из уроков в
репозитории (Встречи 3–7): условия, логические операции, `Math.abs`, массивы и
циклы, методы, ООП (классы, инкапсуляция, наследование, переопределение,
перегрузка, полиморфизм).

**Новое, что добавлено к базовому проекту:** логика **аптечек** (`MedKit`) —
герой подбирает аптечку и получает +1 жизнь.

## Как запустить

```bash
cd src
javac *.java
java -Dstdout.encoding=UTF-8 Main
```

Флаг `-Dstdout.encoding=UTF-8` нужен, чтобы в консоли ровно отображались эмодзи
и кириллица (в IntelliJ IDEA это уже стоит по умолчанию — можно просто нажать Run на `Main`).

## Как играть

1. Ввести размер поля (например, `5`).
2. Выбрать уровень сложности `1`–`5`.
3. Каждый ход вводить координаты соседней клетки через пробел: `x y`.
4. Цель — дойти до замка 🏰. Двигаться можно на одну клетку по вертикали или
   горизонтали.

Обозначения на поле:
- 🧙 — главный герой
- 🏰 — замок (цель, победа)
- 👾 — маленький монстр (простой пример на сложение)
- 👹 — большой монстр (пример сложнее, зависит от уровня сложности)
- ❤ — аптечка (+1 жизнь)

## Файлы (структура ООП)

| Файл             | Что делает |
|------------------|------------|
| `Main.java`      | Начало игры, выбор сложности, генерация поля/замка/героя/монстров/аптечек, игровой цикл, вывод поля (`outputBoard`). |
| `Person.java`    | Главный герой: поля (x, y, image, live), `move`, `isMoveCorrect`, `downLive`, `upLive`, геттеры/сеттеры. |
| `Monster.java`   | Маленький монстр: задание `taskMonster`, `conflictPerson`. |
| `BigMonster.java`| Большой монстр (`extends Monster`): переопределённое `@Override taskMonster` по уровню сложности + перегрузка. |
| `MedKit.java`    | **Аптечка (новая логика):** восстанавливает жизнь при подборе. |
